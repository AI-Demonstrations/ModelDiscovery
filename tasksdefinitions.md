# Hugging Face Model Tasks: Definitions, Use Cases and Examples

Oct 28, 2026 · Companion to [readme.md](readme.md) (Sections 2.1 to 2.3, `hub_search()`)

The **Tasks** filter on the [Hub's model page](https://huggingface.co/models) lists 52 tasks, grouped below the way the Hub groups them. Each task name links to the Hub's model list for that task, and the code value is what you pass as `pipeline_tag=` in `hub_search()`. Examples marked ★ are used in the [model selection walkthrough](readme.md) or the [quantization demo](QuantizationGuide.md). The Hub also has an explanation page for most tasks at `huggingface.co/tasks/<tag>`.

Two things to say in class. First, **the uploader sets the tag**, so it is a guide, not a guarantee. Similar models can carry different tags: FLUX.2 and Qwen-Image-Edit both take an image plus an instruction, but are tagged image-to-image rather than image-text-to-image. Second, **framing the problem picks the row.** The bank's routing problem is text classification, but it could also be framed as zero-shot classification (candidate B), sentence similarity (candidate C), or text generation (an LLM). Each framing leads to a different shelf of models.

Example models were checked on the Hub on Oct 28, 2026. Check each one's license before use: several, noted below, do not allow commercial use or have custom terms.
